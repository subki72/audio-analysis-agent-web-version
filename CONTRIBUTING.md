# Contributing to VoiceScript (Audio Analysis Agent)

We welcome contributions adhering to production engineering standards.

## Local Setup

```bash
git clone https://github.com/subki72/audio-analysis-agent-web-version.git
cd audio-analysis-agent-web-version
make install
```

## Verification Gates

```bash
make lint
make test
```

## Pre-Commit Hooks

```bash
pip install pre-commit
pre-commit install
```
